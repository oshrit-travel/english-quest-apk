# English Quest 2.0 — אפליקציית אנדרואיד (React + Three.js + Capacitor)

משחק הרפתקאות איזומטרי תלת־ממדי ללימוד אנגלית (רמת Basic), ממשק עברי RTL ותוכן אנגלי LTR.
בלי חזירים 🐑🐇🐔🐴🐦 — חיות החווה: כבשים, ארנבים, תרנגולות, סוסים וציפורים.

## מה יש במשחק
6 אזורים עם 37 משימות: כפר ההתחלה, חוות החיות, עיירת בית הספר, היער המסתורי, נמל ההרפתקאות וממלכת האנגלית. כל אזור נפתח אחרי קרב בוס + שליטה אמיתית במספר מילים (לא לפי XP). האזורים מחוברים בגשרים עם שערים.

## הדרך הקלה: APK דרך GitHub (בלי להתקין כלום)
1. ב-GitHub צרו ריפו פרטי חדש בשם `english-quest-apk`.
2. **Add file → Upload files** → גררו פנימה את *כל תוכן* התיקייה (לא את קובץ ה-zip עצמו; חשוב שהתיקייה הנסתרת `.github` תעלה — אם הדפדפן מדלג עליה, ראו הערה למטה).
3. Commit changes.
4. לשונית **Actions** → ה-workflow "Build Android APK" רץ אוטומטית (5–10 דקות). אפשר גם להריץ ידנית: Run workflow.
5. בסיום, בתוך הריצה, ב-**Artifacts** מורידים `english-quest-debug-apk` → זיפ עם `app-debug.apk`.
6. מעבירים לטלפון/טאבלט, מאשרים "התקנה ממקורות לא ידועים", ומתקינים.

> אם `.github/workflows/android.yml` לא עלה בהעלאה: ב-GitHub לחצו Add file → Create new file, כתבו בשם הקובץ `.github/workflows/android.yml` והדביקו את תוכן הקובץ.

אם ה-build נכשל: פתחו את הריצה שנכשלה, העתיקו את השורות האדומות האחרונות ושלחו לי — אתקן.

## הרצה מקומית (למי שיש Node 20+)
```
npm install
npm run dev        # http://localhost:5173
npm test           # בדיקות מנוע הלמידה
npm run build      # dist/
```
בנייה ל-Android מקומית: `npm run build && npx cap add android && node scripts/patch-android.mjs && npx cap sync android` ואז פתיחה ב-Android Studio.

## מבנה
- `src/data/` — כל התוכן הלימודי (מילים, משפטים, קטעי קריאה, משימות, דמויות).
- `src/engine/` — מנוע הלמידה (חזרות מרווחות, קושי אדפטיבי, רמזים, מבחנים, לוח הורים) — בלי תלות ב-UI.
- `src/world/` — העולם התלת־ממדי (React Three Fiber): `layout.ts` הוא מקור אמת יחיד לבניינים/עצים/התנגשויות.
- `src/screens/`, `src/ui/` — מסכי המשחק (React + Tailwind + Framer Motion).
- `.github/workflows/android.yml` — בניית APK.

## מה נבדק ומה לא (כנות)
נבדק: לוגיקת מנוע הלמידה (10 בדיקות ירוקות), הרצה מדומה של כל 37 המשימות לפי הסדר עד הקרב הסופי (כולל פתיחת כל השערים), ושאפשר ללכת על הגשרים מקצה לקצה, תקינות תחביר/ייבוא/ייצוא בכל 26 הקבצים, והיעדר תוכן חזירים.
**לא נבדק**: ה-build המלא וההרצה בפועל — בסביבה שבה כתבתי לא היה גישה ל-npm. לכן ה-build הראשון ב-GitHub עלול להציג שגיאות קטנות, והמראה התלת־ממדי טרם נראה בעין. שלחו צילום מסך/שגיאה ואתקן.
האמנות פרוצדורלית (צורות low-poly בקוד, בלי חבילות מודלים); אייקון האפליקציה ברירת מחדל של Capacitor. בדיקת טיפוסים (`tsc`) רצה ב-CI כמידע בלבד ולא עוצרת את הבנייה.
